# 飞书台账模板使用说明

把本仓库的「投递记录」表结构一键复制到你的飞书多维表格。两种方式任选其一，都不包含任何个人投递数据。

## 方式一：脚本一键建表（推荐，字段类型全自动）

1. 在飞书**新建一个空多维表格**，从链接里复制 `app_token`（`…/base/<app_token>?table=…`）。
2. 在[飞书开放平台](https://open.feishu.cn)创建企业自建应用，开通**多维表格读写权限（bitable:app）**，发布版本；并把第 1 步的表格添加为本应用的可用数据表。
3. 运行：

```bash
python scripts/setup-feishu-template.py \
    --app-id cli_你的AppID --app-secret 你的Secret --app-token 你的app_token
```

脚本会建出「投递记录」表 + 13 个字段（含单选/多选选项、日期格式、关联本表的「父记录」），并打印 `table_id`。把它和 `app_token` 填入 `dashboard/.feishu-app.json` 即完成接入（见 README「接入飞书」）。

## 方式二：导入 CSV（不想创建飞书应用时）

1. 飞书多维表格 → 导入 → 选择 [`sample/feishu_template.csv`](../sample/feishu_template.csv)，得到一张含 12 列和 5 行示例的表。
2. 导入后手动调整列类型（CSV 不携带类型信息）：

| 列 | 改为 |
| --- | --- |
| 单位类型 | 单选，选项：央企国企 / 银行 / 互联网大厂 / 事业单位 / 外企 / 其他 |
| 城市 | 多选，选项自定（北京 / 上海 / 杭州 / 苏州 / 天津…） |
| 投递 | 单选，选项：待投递 / 已投递 / 已截止 / 挂了 / Offer / 实习offer |
| 进展 | 多选，选项：ai面 / 测评 / 笔试 / 一面 / 二面 / 三面 / 体检 |
| 投递日期、报名截止日、最新日期 | 日期 |
| 其余列 | 保持文本 |

3. 手动添加一个**关联字段**：字段名「父记录」，关联**本表**——用于把分行/子岗位记录挂到集团主记录上（CSV 无法表达关联类型）。
4. 建完后删除示例行，开始录入。

> CSV 里的多选值用英文逗号分隔（如 `测评,笔试`），导入后核对是否被拆成多个选项。

## 字段速查

| 字段 | 类型 | 选项 / 说明 |
| --- | --- | --- |
| 公司名称 | 文本 | 集团、分行或子岗位名 |
| 单位类型 | 单选 | 央企国企 / 银行 / 互联网大厂 / 事业单位 / 外企 / 其他 |
| 城市 | 多选 | 工作地点，选项自定 |
| 岗位 | 文本 | 岗位名称 |
| 投递 | 单选 | 待投递 / 已投递 / 已截止 / 挂了 / Offer / 实习offer |
| 进展 | 多选 | ai面 / 测评 / 笔试 / 一面 / 二面 / 三面 / 体检 |
| 投递日期 | 日期 | 实际投递日 |
| 报名截止日 | 日期 | 截止提醒的唯一依据，尽量填全 |
| 最新日期 | 日期 | 无截止日时的参考日期，**不要当作截止日使用** |
| 笔试时间 | 文本 | 如 `2026-11-05 14:00-16:00 笔试` |
| 备注 | 文本 | 材料要求、说明等 |
| 链接 | 文本 | 招聘/投递入口 |
| 父记录 | 关联本表 | 子记录关联集团主记录；不填则为主记录 |

## 配色建议（可选）

与看板语义一致的选项颜色，可在飞书字段设置里手动调整：

- 投递：待投递=蓝、已投递=浅蓝、已截止=黄、挂了=红、Offer=绿、实习offer=橙
- 进展／城市／单位类型：按喜好即可

## 记录组织约定

- **同一集团的不同分行、岗位分别建独立记录**，各自跟踪进展。
- 分行/子岗位记录通过「父记录」关联到集团主记录；集团主记录负责汇总状态（如 Offer、挂了）。
- 有明确截止日的尽量填「报名截止日」，看板的截止倒计时和提醒都依赖它。
